## 🚀 Overview

Architrue Demo is a modern architecture and construction web platform built using **Next.js** and **Tailwind CSS**. 

This project demonstrates scalable UI architecture, reusable component design, internationalization (i18n), and performance optimization in a real-world application setup.

---

## 🛠 Tech Stack

- **Framework:** Next.js (React)
- **Styling:** Tailwind CSS
- **Internationalization:** i18n
- **Deployment:** Vercel
- **Tooling:** Git, VS Code

---

## ✨ Key Features

- 🌍 Multi-language support (English / German)
- 🧩 Modular & reusable component architecture
- 📱 Fully responsive (mobile-first design)
- ⚡ Optimized rendering using Next.js features
- 🔍 SEO-friendly routing structure
- 🎯 Clean and maintainable folder structure

---

## 🌍 Internationalization (i18n)

- Implemented language-based routing
- Structured translation files for scalability
- Dynamic UI updates based on selected locale
- Architecture designed to easily add new languages

---

## 🏗 Architecture Approach

- Separated UI into reusable components
- Maintained scalable folder structure
- Used Tailwind utility-first styling for consistency
- Optimized performance with efficient rendering
